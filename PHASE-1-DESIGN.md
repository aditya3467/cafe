# Cup2Eat Phase 1 Visual Design System

## Direction

Premium sustainable food brand: editorial typography, close-up product photography, forest green as the anchor, warm cream as the breathing space, and caramel gold for action and emphasis. Photography carries the appetite appeal; the interface stays restrained and tactile.

## Tokens

- Forest: `#10372B`
- Deep forest: `#08241D`
- Warm cream: `#F5EFE1`
- Paper: `#FBF8F1`
- Caramel gold: `#C9A15A`
- Ink: `#16332B`
- Sage text: `#B6C7B6`
- Hairline: `rgba(245,239,225,.18)`
- Display: Bricolage Grotesque
- Body: DM Sans
- Script accent: Yellowtail

## Components

- Header: compact sticky bar with wordmark, anchor navigation, gold order action.
- Button: pill shape reserved for actions; outlined secondary action for lower priority.
- Proof rail: small uppercase labels with thin icon circles.
- Product card: image first, flavour name, pack price, single selection action.
- Order builder: dark framed panel, radio chips, stepper, checkbox, transparent prefilled message, live totals.
- Status: concise live feedback below copy action.

## Responsive rules

- Desktop content max-width 1180px, two-column hero and order layout.
- Tablet reduces flavour grid to two columns.
- Mobile uses one-column hero/order and two-column flavour cards, with minimum 44px controls.
- Images use `object-fit: cover` with consistent editorial crops and real asset paths.
- Reduced-motion preference disables reveal transforms and ticker animation.
